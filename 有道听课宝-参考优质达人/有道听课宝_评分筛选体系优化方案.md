# 有道听课宝评分筛选体系优化方案

生成日期：2026-05-26

参考数据来源：`有道听课宝-参考优质达人`

本方案基于 126 位参考优质达人，其中 121 位已补采到主页详情和近期笔记。目标是把有道听课宝的评分筛选体系，从“按通用教育达人规则打分”优化为“围绕留学生听课/学习效率场景的 KOC 项目三阶段评分”。

## 0. 项目类型判断

有道听课宝应明确按 KOC 达人投放项目处理。

判断依据：

- Brief 明确要求达人量级为 KOC。
- 单达人预算集中在 1000 元以内，参考达人报价中位约 ¥600。
- 参考达人粉丝中位约 4300，明显不是 KOL 或中腰部达人逻辑。
- 投放目标更接近多账号矩阵种草、留学生真实学习场景铺设、听课/笔记/课堂效率工具的内容验证。
- 产品需要的是“真实留学生使用感”和“学习场景可信度”，不是头部曝光或专业背书。

因此，听课宝不应按泛教育 KOL 或留学大号逻辑评分，而应启用 KOC 通用结构：

```text
一阶段基础筛选 -> 二阶段详情补采 -> 三阶段项目匹配评分
```

项目类型配置建议：

```text
project_delivery_type：KOC 达人投放
creator_matrix_type：低预算留学生 KOC 矩阵
is_koc_project：true
koc_activation_reason：Brief 明确 KOC，预算低，参考达人以小粉高效真实留学生账号为主
koc_activation_confidence：high
```

## 1. 参考达人反推结论

### 1.1 核心画像

这批优质达人不是大粉型账号，而是低粉、高效率、强场景 KOC。

| 指标 | P25 | 中位数 | P75 |
|---|---:|---:|---:|
| 粉丝数 | 2400 | 4300 | 6500 |
| 报价 | ¥400 | ¥600 | ¥780 |
| 阅读中位数 | 1279 | 2402 | 4117 |
| 互动中位数 | 116 | 274 | 461 |
| CPE | 1.15 | 2.16 | 3.81 |
| CPM | 24.63 | 40.72 | 65.85 |

关键结论：

- 粉丝量不应成为高权重项，低粉不等于弱号。
- 报价、阅读、互动、CPE 更能解释这批优质达人。
- 视频占比高，但图文高效率达人也应该保留。
- “留学/海外身份”是入口条件，“学习场景内容”是最终推荐条件。

### 1.2 内容信号

已补采 121 位达人近期笔记后，内容信号如下：

| 信号 | 命中人数 | 使用方式 |
|---|---:|---|
| 学习类内容占比 >= 50% | 103/121 | 二阶段核心推荐条件 |
| 留学/海外痕迹 >= 25% | 101/121 | 二阶段身份确认条件 |
| 冲突内容占比 >= 50% | 92/121 | 不直接淘汰，但必须人工复核或降权 |
| 低赞风险 | 7/121 | 二阶段风险项 |

注意：留学生账号天然会有 vlog、旅行、穿搭、生活记录，不应只因出现这些内容就 Pass。应判断“学习/课堂/作业/考试/论文等内容是否足够支撑听课宝植入”。

## 2. 现有体系主要问题

### 2.1 一阶段和二阶段边界不清

现有评分容易在字段不完整时直接给强推荐或淘汰结论。听课宝项目里，学习类内容占比、低赞风险、是否全是 vlog、是否接过商单，都必须依赖详情页和近期笔记，不能只靠列表字段判断。

### 2.2 粉丝量权重仍然偏显性

参考达人粉丝中位只有 4300，但阅读和互动表现扎实。若评分体系过度奖励粉丝量，会错过这类低粉高效率账号。

### 2.3 “冲突内容”判断过粗

留学生达人常见内容包括旅行、日常、穿搭、vlog。如果把这些直接作为强负向，会误伤大量真实留学生账号。应改成占比判断和植入空间判断。

### 2.4 内容占比缺少可计算口径

“学习类内容 50% 以上”目前容易被模型主观判断。应改为近 8-20 篇笔记中，标题/正文命中学习场景的数量占比，并保留证据标题。

## 3. 优化后的总体流程

建议改为三阶段：

`一阶段基础筛选 -> 二阶段详情补采 -> 三阶段项目匹配评分`

### 3.1 基础入库

入库字段以现有 Excel 和蒲公英列表字段为主：

- 达人基础：昵称、蒲公英链接、小红书主页链接、账号类型、人设标签
- 投放基础：合作形式、图文报价、视频报价、平台报价、执行价
- 数据基础：粉丝数、获赞收藏、阅读中位数、互动中位数、CPM、CPE
- 链接身份：蒲公英 blogger_id、小红书 profile_id
- 原始证据：raw_payload、来源文件、来源行号

这一阶段不输出最终推荐，只输出“是否值得补采详情”。

### 3.2 一阶段基础筛选

一阶段只使用已采集的稳定字段。

建议输出：

- `优先补采`
- `可补采`
- `低优先级`
- `数据暂缓`
- `一阶段 Pass`

一阶段可硬 Pass 的情况：

- 无蒲公英链接且无可补全主页链接
- 图文和视频报价都明确超过预算，且无特殊高效理由
- 已明确不可接单或无商业权限
- 明确回复率低于 50%

一阶段不能直接 Pass 的情况：

- 缺少主页简介
- 缺少近期笔记正文
- 暂未确认学习类内容占比
- 暂未确认是否低赞
- 有旅行、日常、vlog 等标题，但未确认占比

## 4. 一阶段评分规则

### 4.1 推荐权重

将听课宝项目一阶段权重调整为：

```json
{
  "budget_fit": 20,
  "cost_efficiency": 22,
  "read_interaction_quality": 23,
  "identity_weak_signal": 15,
  "content_weak_signal": 10,
  "execution_certainty": 10
}
```

解释：

- `budget_fit` 高权重：参考达人报价中位 ¥600，预算适配是核心优势。
- `cost_efficiency` 高权重：参考达人 CPE 中位 2.16，效率区分度强。
- `read_interaction_quality` 高权重：阅读和互动比粉丝量更能解释优质 KOC。
- `identity_weak_signal` 保留：一阶段可用账号类型判断留学/海外弱信号。
- `content_weak_signal` 保留：一阶段只看标题/标签弱证据，不做最终内容判断。
- `execution_certainty` 单独列出：回复率、商单、近期更新必须独立看。

如果系统暂时仍使用现有六维结构，可先映射为：

```json
{
  "budget": 20,
  "fans": 5,
  "cpe": 22,
  "engagement": 28,
  "persona": 15,
  "content": 10
}
```

其中 `fans=5` 只作为量级坐标，不因低粉扣分。

### 4.2 一阶段分项规则

| 维度 | 满分 | 评分建议 |
|---|---:|---|
| 预算适配 | 20 | <=¥800 满分；¥801-1000 高分；¥1001-1600 备选；>¥1600 降权 |
| CPE 效率 | 22 | <=3.8 强；3.8-7 可；7-10 观察；>10 降权 |
| 阅读互动 | 23 | 阅读>=2400 且互动>=274 强；阅读>=1000 且互动>=100 可补采 |
| 身份弱信号 | 15 | 账号类型含海外留学生/留学背景加分；需二阶段验证 |
| 内容弱信号 | 10 | 标题/简介已有学习、课堂、笔记、论文、考试等词加分 |
| 执行确定性 | 10 | 回复率、可接单、近期更新、商单证据；缺失则待补，不直接淘汰 |

粉丝量不进入正向高权重，只作为同量级比较坐标。

### 4.3 一阶段分档

| 分档 | 条件 |
|---|---|
| 优先补采 | 报价<=1000，阅读>=1000，互动>=100，CPE<=7，留学/海外弱信号匹配 |
| 可补采 | 至少三项达标，或报价略超但阅读/互动高于 P75 |
| 低优先级 | 数据低于 P25，但身份匹配，仍可保留少量样本 |
| 数据暂缓 | 关键字段缺失，无法判断 |
| 一阶段 Pass | 明确超预算、不可接单、链接不可用、回复率<50% |

## 5. 二阶段补采字段

二阶段必须补齐以下字段后再给最终推荐：

| 字段 | 来源 | 用途 |
|---|---|---|
| 主页简介/detail_text | 蒲公英详情/小红书主页 | 判断留学身份和人设自然度 |
| 近期笔记标题 | 近 8-20 篇笔记 | 计算学习内容占比 |
| 近期笔记正文 | 近 8-20 篇笔记 | 判断是否有课堂/听课/作业/论文场景 |
| 笔记发布时间 | 近期笔记 | 判断近 30 天是否更新 |
| 点赞/收藏/评论 | 近期笔记 | 判断低赞风险和互动质量 |
| 笔记类型 | 近期笔记 | 判断视频/图文主形态 |
| 合作笔记案例 | 蒲公英详情 | 判断是否接过商单和商业内容自然度 |
| 48h 回复率 | 蒲公英详情 | 低于 50% 才硬 Pass |

## 6. 二阶段评分规则

### 6.1 二阶段硬规则

以下条件不满足，不进入强推荐：

- 必须能证明留学生/留学背景/海外学习经历。
- 近 30 天应有更新，缺失则待确认。
- 学习类内容占比应 >= 50%，否则最多备选。
- 推荐投放形式预算内。
- 不能频繁出现非当天个位数/十几点赞。
- 不能主推与项目强冲突的内容，如美食、母婴、纯探店。
- 回复率明确低于 50% 时 Pass。

二阶段不要因为“vlog、旅行、日常”单独 Pass。留学生 KOC 天然会有生活内容，关键是是否仍有足够学习/课堂/听课/论文/考试场景承接听课宝。

### 6.2 学习类内容占比口径

计算对象：近 8-20 篇笔记。

命中关键词：

- 中文：学习、上课、听课、课堂、课程、笔记、复习、备考、考试、论文、作业、自习、图书馆、专业、学校
- 英文：essay、assignment、lecture、final、presentation、seminar、GPA
- 留学学习场景：港硕、留学、研究生、硕士、校园、网课、课表

评分建议：

| 学习内容占比 | 结论 |
|---:|---|
| >=70% | 内容强匹配 |
| 50%-70% | 内容匹配 |
| 30%-50% | 备选，需看植入空间 |
| <30% | 不推荐，除非有强学习爆文或强身份价值 |

### 6.3 低赞风险口径

计算对象：近 8-20 篇非当天笔记。

| 情况 | 处理 |
|---|---|
| 低于 20 赞笔记占比 <20% | 低风险 |
| 20%-40% | 中风险，降一级 |
| >40% 且样本>=3篇 | 高风险，不推荐 |
| 当天发布低赞 | 不计入硬风险 |

### 6.4 冲突内容口径

冲突内容包括：美食、母婴、穿搭、探店、纯旅行、纯生活流水账、纯情绪。

处理原则：

- 出现冲突内容不直接淘汰。
- 冲突内容占比 >=50% 时，需要判断是否仍有学习/留学主线。
- 如果学习内容占比 >=50%，冲突内容只作为表达风格，不作为硬伤。
- 如果学习内容 <30% 且冲突内容 >=50%，不推荐。

## 7. 最终推荐分档

### 强推荐

条件：

- 报价 <= ¥1000
- CPE <= 3.8
- 阅读 >= 2400 或互动 >= 274
- 留学/海外身份证据明确
- 学习类内容占比 >= 50%
- 低赞风险低
- 有自然植入场景，如听课、课堂记录、课后复盘、论文、assignment、lecture、final
- 不是仅靠生活方式出片，而是能讲清听课/学习效率痛点

### 推荐

条件：

- 报价 <= ¥1000，或 ¥1000-1600 但数据显著高于 P75
- 学习类内容占比 >= 50%
- 留学身份明确
- CPE <= 7
- 无明显低赞风险
- 可推荐图文或视频，按预算内形态执行

### 备选

条件：

- 身份匹配，但学习内容占比 30%-50%
- 报价略超预算但数据优秀
- 图文/视频某一形态预算内
- 冲突内容占比较高但仍有学习场景
- 生活/vlog 占比高，但有少量强学习爆文或强留学身份

### 待人工确认

条件：

- 缺少近期正文
- 缺少回复率
- 缺少商单证据
- 低赞风险无法判断
- 身份或学习内容证据不足

### 不推荐 / Pass

条件：

- 明确非留学生/无留学背景
- 学习内容占比 <30%，且无强学习爆文
- 回复率明确 <50%
- 非当天低赞笔记占比 >40%
- 图文和视频均超预算，且效率不突出
- 主推美食、母婴、探店等强冲突内容

## 9. 评分提示词优化

建议在有道听课宝评分提示中加入以下约束：

```text
你正在为“有道留学听课宝”筛选小红书达人。不要按泛教育或泛留学达人打分。

这是一个 KOC 达人投放项目。项目核心是：低预算留学生 KOC 矩阵 + 真实海外课堂/听课/笔记/论文/考试/课后复盘等学习效率场景。

不要按 KOL 或中腰部达人逻辑奖励粉丝规模。粉丝量只作为同量级比较坐标。

评分必须分两阶段：
1. 一阶段只用已采集字段做补采优先级排序，不给最终强推荐。
2. 二阶段必须基于主页简介、近期笔记标题、正文、点赞、发布时间、笔记类型和合作案例做项目匹配判断。

低粉不是扣分项。参考优质达人粉丝中位约 4300，报价中位约 600，阅读中位约 2400，互动中位约 274，CPE 中位约 2.16。请更多关注同量级下的阅读、互动、报价和 CPE。

视频优先，但不能排除图文高效账号。若图文账号报价低、互动好、学习场景强，可以推荐图文投放。

旅行、穿搭、日常、vlog 在留学生账号中常见，不能单独作为淘汰理由。只有当学习内容占比低且冲突内容占比高时，才降权或不推荐。

学习类内容占比必须基于近 8-20 篇笔记标题/正文计算。低赞风险必须基于近 8-20 篇非当天笔记点赞样本判断。字段缺失时输出待补或待人工确认，不要猜测。
```

## 10. 落地优先级

### P0：立即调整

1. 在项目配置中明确 `is_koc_project=true`，达人矩阵类型为“低预算留学生 KOC 矩阵”。
2. 更新听课宝项目评分权重。
3. 将一阶段输出改为补采优先级，不直接强推荐。
4. 把预算、阅读、互动、CPE 参考基准写入项目配置。
5. 把学习内容占比、低赞风险、冲突内容占比改为二阶段证据项。

### P1：补充字段

1. 增加 `study_content_ratio`。
2. 增加 `overseas_trace_ratio`。
3. 增加 `low_like_risk`。
4. 增加 `format_budget_fit`。
5. 增加 `recommended_format`。

### P2：评分闭环

1. 用这 126 位参考达人作为正样本基准。
2. 每次新采达人计算 `reference_similarity_score`。
3. 人工通过/淘汰结果回写，持续校准阈值。
4. 对强推荐达人保留 3-5 条标题/正文证据，方便复盘。
